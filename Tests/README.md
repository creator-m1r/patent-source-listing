# Tests

Минимальный план проверки:

1. Выбрать проект с вложенными каталогами.
2. Проверить рекурсивное чтение Swift/C++/Python/JS и других поддерживаемых текстовых файлов.
3. Проверить исключение `.git`, `build`, `DerivedData`, `node_modules` и бинарных/медиа-файлов.
4. Проверить Unicode-дерево.
5. Проверить логический порядок исходников.
6. Проверить разделитель и относительный путь перед каждым файлом.
7. Проверить SHA-256.
8. Открыть сформированный RTF в совместимом редакторе.
